# FARM-TECH

FARM-TECH is a web-based agricultural platform for Indian farmers.

## Initial Development Scope
- Agricultural marketplace
- Buy / sell / rent farming products and equipment
- Basic bidding
- Farmer-to-farmer and farmer-to-customer workflows
- AI farming guidance (later module)

## Project Structure

- `backend/` — Node.js + Express API
- `frontend/` — React frontend

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Environment variables belong in `backend/.env`. Never commit `.env`.
Use `backend/.env.example` as the template.
